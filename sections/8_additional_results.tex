\section{Experimental Protocols and Additional Results}
\label{sec:appendix-experiments}

This appendix records the exact scope, CARAT configuration, loss convention, and provenance underlying Section~\ref{sec:experiments}.

\subsection{Completed Empirical Scope}

The completed comparison covers CIFAR-100/ResNet18 with $20$ fully participating clients, Dirichlet non-i.i.d.\ partitions, $20\%$ malicious clients, and five attacks: ALIE, FangAttack, MinMax, MinSum, and Mimic. The paper reports Mean, NormClipping, MultiKrum, FLTrust, FLDetector, and CARAT. The CARAT sweep contains all combinations of three displayed heterogeneity levels, five attacks, and five seeds. Compatible baseline values also use five seeds; the available archive does not contain the Mimic--Mean cell, which is left unreported.

\subsection{Result Provenance and Integrity Checks}

The CARAT client-$20$ sweep contains $960$ completed runs across two datasets, four data-distribution settings, four malicious-client ratios, six attacks, and five seeds. The main paper selects the $75$ CIFAR-100/ResNet18 runs with $\alpha\in\{1,0.5,0.1\}$, malicious ratio $0.2$, and the five displayed attacks. Every selected metric file contains all $200$ training rounds. Job metadata records code commit \texttt{70920a89}, the launch command, configuration, seed, Python environment, and CUDA requirement. The extracted CARAT-only archive has SHA-256 checksum \texttt{382bac20d9a44dffa41e8b36de1c05943c69d20d4cb1107e6e2963a6bca97134}.

The component study contains $100$ completed runs: five variants, four attacks, and five seeds, each with $200$ rounds. It was executed independently on the laboratory server. Because concurrent jobs make wall-clock measurements sensitive to contention, these runs support the accuracy ablation in Table~\ref{tab:carat-ablation} but are not used for a runtime claim.
