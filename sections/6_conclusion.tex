\section{Conclusion}
\label{sec:conclusion}

CARAT validates candidate updates through hidden, class-balanced task certificates rather than geometric centrality or a single trusted reference direction. In the completed CIFAR-100/ResNet18 non-i.i.d.\ evaluation with matched trusted-data budgets, it achieves the strongest performance among the reported public baselines under four untargeted model-poisoning attacks, supporting its use when a modest labeled server reference set is available.
